# Existing measurement boundaries

- ocr_bench dispatches synth/private and uses a safe parser; synth_bench normalizes NFC and Unicode whitespace for CER. Existing field_matches is not an exact-field metric.
- private_bench provides 300dpi raster_pages and native/Python quiet_dependencies. Its contains/date-list field contracts are unsuitable for strict exact scoring; reuse primitives, not contains semantics.
- make_gt is interactive and supports four of the requested five types; synthetic truth must be authored noninteractively with an explicit qualification contract.
- make_synth_eval renders CJK synthetic pages and implements phone_capture. Existing suite covers only three types and contains a mixed acquisition title; do not use that as independent classification truth.
- verify_upload exposes shared assess_upload and quiet/read-only assessment protection; verify_cases._private_location enforces symlink-resolved external-or-ignored/untracked targets and _unique_object rejects duplicates.
- nhis_form_samples and p2_payment_samples contain fictitious, coordinate-complete forms suitable for synthetic source reuse. No actual private input is required.
- LocalOcr selects type independently of expected slot; read_document normalizes file evidence and required fields. Benchmark must restrict the chain to local/PDF readers, force own and retain standard postprocessing.
