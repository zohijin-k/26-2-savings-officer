## 3. 실제 화면 확인

격리 서버(이 저장소의 백엔드 코드, 임시 DB와 임시 저장 폴더, 8000번)에 신청자 프런트(5173)와 담당자 프런트(5174)를 붙였다. 브라우저 창이 가려진 상태라 화면 조작은 스크립트로 입력과 클릭을 보내는 방식으로 했고, 결과는 화면의 글자와 API 응답으로 확인했다. 화면 그림은 남기지 않았다.

| 단계 | 한 일 | 본 것 |
|---|---|---|
| 본인인증 | 신청자 화면에서 합성 신청인 입력, 서약, 서명 파일 올리기 | 2단계로 넘어감 |
| 서식 작성 | 화면 대신 이 저장소의 시연 도구(`seed_application`)로 합성 값을 채움 | 3단계 화면에 "2단계 완료" |
| 업로드 | 신청자 화면에서 근로유형 선택, 발급일 입력, 합성 서류 5종(적합 묶음) 올리기 | 5종 모두 "업로드 완료" |
| 신청자 응답 | 서류 목록과 최종 확인 API 응답 확인 | 상태는 모두 `UPLOADED`, 사유 0개, 내부 판정·신뢰도·점수 키 없음. 제출 가능 |
| 제출 전 담당자 목록 | 담당자 목록 API | 0건(초안은 안 보임) |
| 제출 | 신청자 화면에서 신청 제출 | "신청이 접수되었습니다", 신청번호 DS-2026-000001 |
| 담당자 목록 | 담당자 화면 | 확인 필요 탭에 DS-2026-000001이 접수 일시와 함께 표시 |
| 담당자 상세 | 그 건을 열어 봄 | 서류 5종 적합, 원본이 화면 안에서 열림(응답이 `inline`), 사유 2건, 심사표 99점 |
| 담당자 결정 | 보류, 최종 선정을 차례로 누름 | "담당자 판단을 저장했습니다" |
| 신청자 마이페이지 | 진행 상황 확인 | 보류일 때 자격심사 진행 중, 최종 선정일 때 결과발표 진행 중. 점수 없음 |

- 임시 DB에는 신청 1건, 서류 5건(저장된 판정은 모두 `PASS`), 담당자 결정이 있는 심사 1건이 남았다. 신청자에게는 `UPLOADED`로만 보였다.
- 담당자 화면의 AI 제안이 "확인필요"였던 것은 시연 도구가 채운 서식 값이 합성 서류의 값과 달라서다(가구원 수가 다름, 근로 계속성 근거 부족). 연결과는 무관하다.
- 확인 뒤 이 저장소의 시연 DB는 그대로였다(제출 2건, 담당자 결정 0건). 신청자 저장소의 DB도 그대로다.
- 문서에 적은 명령과 같은 구성(이 저장소 백엔드 8000, 프런트 5173·5174)도 띄워 봤다. 담당자 화면에 기존 시연 신청 2건이 보였고, 신청자 화면이 본인인증 단계로 열렸다. 이때는 자료를 쓰지 않았다.

## 5. 계획과 달라진 점

- 화면 확인에서 서식 작성 단계는 화면으로 하지 않았다. 서식 5종을 화면에서 채우는 대신 이 저장소의 시연 도구가 쓰는 함수를 격리 서버에서 불러 합성 값을 넣었다. 본인인증, 업로드, 제출, 담당자 결정, 마이페이지는 화면에서 했다.
- `apply_merge.py`의 `check`가 손으로 고친 파일 5개(시험 3개, 규격 2개)를 알도록 목록을 더했다.
- 연결 실행 규격은 옮겨 온 `applicant-submission.md`에 덧붙이지 않고 새 파일 `unified-backend.md`로 썼다. 옮겨 온 파일은 신청자 저장소의 것과 같게 두기 위해서다.

## 6. 원격 main의 변동

작업하는 동안 원격 `main`이 f6d9827에서 574eb5f로 앞서갔다(PR #15, 측정 도구 `engine_v2/tools`와 그 시험·규격·태스크 기록). 이 변경과 겹치는 파일은 `.trellis/spec/backend/index.md` 하나이고, 3방향 병합에 충돌이 없다(양쪽이 표에 서로 다른 줄을 더했다). 백엔드와 그 시험은 그 도구를 가져다 쓰지 않는다. 최신 `main`에 얹은 상태로 전체 시험을 다시 돌리지는 않았다.

## 7. 이 PC에서 확인하지 못한 것

- `fcntl`을 쓰는 13개 시험 모듈(엔진 12, 백엔드 `test_payment_stage2_routes.py` 1). 리눅스나 맥에서 한 번 돌려야 한다.
- 확인 도구의 명령줄 시험처럼 이 PC에서 변경 전부터 실패하는 시험들. 이 변경이 그 시험에 미치는 영향은 이 PC에서 가릴 수 없다.
- 화면의 모양. 글자와 응답만 확인했다.
- 자체 OCR로 읽는 경로. 화면 확인의 합성 서류는 시연용 고정 판독 응답을 쓴다. 판독 경로는 자동 시험이 다룬다.
