# Approved measurement design

1. Add a source-validity gate before benchmark scoring. Validate actual rendered geometry and observed title separation, not only PDF text extraction in insertion order. Verify embedded font identity/hash and all source glyphs. Reuse existing locally bundled fonts where available; if named fonts are missing, fail explicitly or identify the selected bundled CJK font, never silently claim a different font. Do not download/install fonts as part of an unattended measurement.
2. Retain ambiguous source layout: the insurance purpose/title proximity and payment header geometry are not proven impossible in real documents and therefore are not repaired. Validate with text-layer, perfect-word-geometry classification and own image reads; disclose baseline classification/routing limitations and preserve all purpose markings in stress variants. Never rewrite source wording merely to satisfy a keyword or weaken recognition/rules.
3. Split reported layers: page OCR coverage/CER, independent type accuracy, conditional extractor field accuracy and end-to-end field availability/exactness. Mark extraction-not-invoked separately; do not replace independent classification with truth-selected extraction. A truth-selected extractor is a labeled diagnostic control only.
4. Add field-aware symmetric canonicalization before normalized exact scoring, retaining raw exact as an audit column. Use Unicode NFKC, whitespace policy, validated ISO dates, numeric-only comma removal and reviewed hyphen equivalents. Preserve identifier leading zeros, meaningful address punctuation, empty-versus-missing distinction and structured list order. CER normalization and exact normalization must be named explicitly; no blanket punctuation deletion or imputation of missing fields.
5. Give every case explicit expected content validity, expected image acceptability and expected status class. Low-resolution quality violations go into quality defects. Keep original-only normal baseline and per-condition stress views separate. Reclassification is authored before seeing verdicts, never inferred from observed FAIL. Retain every case and its sample identifier in the report.
6. Expand to at least five unique cases per document/condition after base-source validity is established. Current name modulo-four repetition must not create the fifth case as a duplicate of the first. Use five independent authored parameter sets and disclose shared layout/font correlation; adding five names alone is not five independent layouts.

Boundaries: only benchmark tools, new benchmark tests and documentation may change. OCR, extractors, classifiers, adapters and verdict logic stay unchanged. Keep the previous report as a versioned record with a supersession note, not a retroactive overwrite of history.

## Conservative implementation decision

No existing original-layout correction is authorized by evidence. The purpose/title proximity and payment header layout can occur in documents and are ambiguous, so both are retained unchanged. Do not fix these to make baseline metrics pass. Preserve them in original and stress paired runs, identify stage-A failures explicitly. Only the modulo-four duplicate-sample generator bug is corrected by five distinct fictitious identity/date parameter sets; this does not alter layout or remove labels. Source changes cite legacy sources() and existing synthetic fixture providers.

Each image case gets reference words from its generated PDF text layer, transformed to the same image coordinates (including rotation/perspective) and fed through the same local upload reader by scoped benchmark-only OCR injection. Use the same input source metadata, renderer, policy and production routing for both stages. Reference has perfect recognized text and confidence1; differences also include OCR segmentation/boxes/confidence, not a controlled glyph-only causal estimate.

A legacy-compatible new staged CLI/module preserves the old suite/API/tests. It records no extracted values, only reviewed field names, states/counts/edits/rates/status codes. Reference and own classify independently; never choose a production extractor by truth. Actual source type and expected upload slot are separate for wrong-slot defects.
