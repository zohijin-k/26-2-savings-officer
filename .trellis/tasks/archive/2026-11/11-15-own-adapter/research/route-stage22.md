| 입력 | --before RESULT_DIR --after RESULT_DIR. 실제 문서 루트 접근 없이 결과 JSON만 읽는다. 임의 결과 키·중복·훼손된 행·비호환 설정은 고정 코드로 거부한다. |
| 집계 단위 | 등록 서류 종류 × 필드 ASCII 코드 × 엔진 × 변형의 전체 격자. 미측정은 NA와 분모0. 존재하는 결과만 출력해 미측정을 숨기지 않는다. |
| 일치율 | 원 정의의 match/eligible을 전/후/차이(%p)로 출력하고 분자/분모를 함께 표시한다. |
| 인식 지표 | 기존 문자 CER와 단어 F1의 전/후/차이(%p). 쪽 평균과 pooled 값을 구분하며 원 집계 함수를 재사용한다. |
| 시간 | 기존 OCR 및 OCR+추출의 쪽당 시간 전/후/차이(초). 시간 차이를 %p로 표기하지 않는다. 측정 기회·전체 시도 분모도 표시한다. |
| 비교 가능성 | ID/쪽/종류/엔진/변형의 코호트 차이를 숫자/고정 상태로 표시한다. 루트 digest 차이는 원문 없이 상태로만 알린다. 합성 동일성은 보존된 바이트 목록으로 별도 입증한다. |
| 출력 | 숫자·고정 코드·NA만 stdout에 출력한다. 파일명/ID/경로/값/좌표/해시/예외 메시지 출력은 0건이다. --help와 오류 경로도 같은 경계를 지킨다. |

모든 후속 사용자 실행 명령의 실서류 경로는 채팅에만 둔다. 현재 단계는 이 설계와 알려진 기대값 영향의 승인을 요청하는 지점에서 멈춘다.
